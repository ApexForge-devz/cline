> **Fork-specific installation note:** This repository does not publish the official Cline desktop installer, the official VS Code Marketplace extension, or a CLI package under the upstream `cline` npm name. Do not use upstream download or npm instructions for this fork. Build from this repository's `my-local-changes` branch using the steps below.

## Choose Your Install Path

- [Desktop App](#desktop-app) — Cline as a native app
- [IDE Extension](#ide-extension) — VS Code, Cursor, JetBrains, Windsurf, VSCodium, Antigravity
- [CLI](#cli) — terminal workflows
- [Kanban](#kanban) (preview) — easily manage multiple agents through a kanban board
- [SDK](#sdk) — build with `@cline/sdk`

## Desktop App

Use this if you want Cline outside your editor, as a native desktop app with a dedicated workspace for running and managing agent sessions.

<Steps>
  <Step title="Build Desktop from source">
    From the repository root, run `bun install` and `bun run build:sdk`, then follow the [desktop app build guide](https://github.com/ApexForge-devz/cline/blob/my-local-changes/apps/examples/desktop-app/README.md). The fork does not provide a hosted installer or auto-update feed.
  </Step>
  <Step title="Choose a provider and model">
    Select the provider and open weight model of your choice. Cline Desktop is an open source app for open weight models, so you bring your own model access.
  </Step>
  <Step title="Start a session">
    Run sessions in parallel, schedule recurring tasks, and import sessions from other coding agents to continue in Cline.
  </Step>
</Steps>

More details: [Cline Desktop](/usage/cline-desktop), and for remote machines [Cline Desktop SSH](/usage/cline-desktop-ssh)

## IDE Extension

Use this if you want Cline inside your editor UI.

<Note>
  This fork does not publish a VS Code Marketplace or Open VSX extension. Build the extension from the repository's `apps/vscode` source.
</Note>

<Steps>
  <Step title="Install repository dependencies">
    From the repository root, run `bun install` and `bun run build:sdk`.
  </Step>
  <Step title="Start the extension development build">
    Run `bun install` and `bun run dev` from `apps/vscode`.
  </Step>
  <Step title="Launch it locally">
    Open the repository in VS Code, open `apps/vscode`, and press **F5** to launch the Extension Development Host.
  </Step>
</Steps>

This fork does not provide a JetBrains Marketplace release.

## CLI

Use this if you want Cline in terminal workflows (interactive + automation).

<Steps>
  <Step title="Install Bun">
    Install Bun, then clone this repository's `my-local-changes` branch.
  </Step>
  <Step title="Build and run the CLI">
    From the repository root, run:
    ```bash
    bun install
    bun run build:sdk
    bun run cli
    ```
  </Step>
  <Step title="Authenticate">
    ```bash
    cline auth
    ```
  </Step>
  <Step title="Run a task">
    ```bash
    bun run cli
    bun run cli -- "your task"
    ```
  </Step>
</Steps>

More details: [CLI Installation & Setup](/usage/cli-overview)

## Kanban

Use this if you want task-board workflows with agent execution.

<Steps>
  <Step title="Install Node.js">
    Install Node.js 18+.
  </Step>
  <Step title="Launch Kanban">
    ```bash
    npx kanban
    ```
  </Step>
</Steps>

More details: [Kanban](/usage/kanban)

## SDK

Use this if you are building your own app/agent on top of Cline.

<Steps>
  <Step title="Create project">
    ```bash
    mkdir my-agent && cd my-agent
    npm init -y
    ```
  </Step>
  <Step title="Build SDK packages from source">
    The fork does not publish the upstream `@cline/sdk` npm package. From the repository root, run `bun install` and `bun run build:sdk`.
  </Step>
  <Step title="Run an example">
    Browse the fork's [SDK examples](https://github.com/ApexForge-devz/cline/tree/my-local-changes/sdk/examples) and use the workspace packages locally.
  </Step>
</Steps>

Start here: [SDK Examples](/sdk/examples)
